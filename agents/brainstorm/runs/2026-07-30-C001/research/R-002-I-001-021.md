## Idea echoed
- **Title:** Evidence-typed, non-summable verdicts — ADVANCE requires a quotable citation, default REJECT.
- **Description:** Findings are tagged MECHANICAL (deterministic from source/DOM/tokens) or PERCEPTUAL (a hierarchy/discoverability/feel judgement). A verdict may only be as strong as its evidence class permits. (1) Mechanical and perceptual scorecards refuse to sum — no single aggregate "UX score". (2) Verdicts default REJECT; flip to ADVANCE only if the reviewer quotes the exact source line/artifact proving the claim.
- **Riskiest assumption:** A citation requirement prevents ungrounded assertion rather than producing decorative but non-supporting citations (citation theatre).
- **Warrant:** An eyeless reviewer that cannot be structurally stopped from asserting perceptual conclusions produces confident-blind verdicts — the failure mode most likely to make the loop worthless.

## Steelman (1 paragraph)
An eyeless single-model loop cannot see a rendered page, so any perceptual claim is unfalsifiable bluffing. Two structural fixes need no model diversity: (a) type each finding by evidence class so the loop cannot launder an unverifiable judgement into a checkable number by averaging — a demand the composite-indicator literature independently reaches as "non-compensatory aggregation"; (b) default REJECT + require a verbatim quote, shifting the burden onto grounded evidence. The repo already runs this pattern for code review (`file:line` citations, severity typing, default-negative gate), so it is a proven local idiom.

## Toulmin decomposition
- **Claim:** Evidence-typing + refuse-to-sum + citation-gated default-REJECT structurally prevents ungrounded perceptual verdicts.
- **Grounds:** (i) Composites of incommensurable measures are statistically meaningless unless non-compensatory — "apples with oranges" [1]; compensatory (linear/geometric) aggregation lets a strong dimension mask a weak one, only non-compensatory schemes preserve incommensurability [2]. (ii) The repo already types findings and cites `file:line` (`cd-review/LOOP.md:38`; `REVIEW-LENS.md:87`) under a default-negative gate (`LOOP.md:532-536`). (iii) An anti-hallucinated-citation pipeline *semantically* checks whether a source supports the claim (cosine<0.6 → `content_mismatch`), not mere presence (`brainstorm/LOOP.md:727-730`).
- **Warrant:** Barring aggregation of unlike evidence + forcing quotable proof removes the mechanism by which blind assertion passes.
- **Backing:** Attribution literature (NLI/AutoAIS/CAQA: Supported/Insufficient/Contradictory/Irrelevant) shows non-support is automatically detectable [3].
- **Qualifier:** Holds strongly for MECHANICAL claims; weakly for PERCEPTUAL ones.
- **Rebuttal:** Up to **57% of citations are non-faithful/post-rationalized** [3] — theatre is rampant; and default-REJECT/extra-option framing induces *Abstention Inflation*, decorative refusals even when the model could answer [4].

## Falsification attempt
- **Falsifier proposed:** If models reliably emit citations that are formally present but semantically non-supporting AND no automated check catches that, the gate is theatre and the idea fails.
- **Falsifier tested via:** ExaSearch (attribution-faithfulness corpus) + ExaContents live-fetch of [3][4]; repo grep of `LOOP.md`/`REVIEW-LENS.md` §6.4 pipeline.
- **Outcome:** *Partially refuted.* Non-supporting citations are frequent (57%, [3]) — the first half of the falsifier holds. But the second half fails: non-support IS auto-detectable (NLI/AutoAIS/CAQA), and `brainstorm/LOOP.md:727` already deploys a semantic (embedding-cosine + title/author) mismatch check, not a presence check. The falsifier survives only for the *perceptual* class, where no ground-truth artifact exists to embed a `file:line` against.

## Position-swap reconciliation
- **Supporter:** Typing + non-summation is what measurement theory prescribes [1][2]; the repo proves the citation-gate idiom works, and §6.4's semantic check defeats theatre.
- **Detractor:** §6.4 verifies URL→body entailment. A PERCEPTUAL verdict cites source lines that cannot entail a feel/discoverability conclusion — cosine has nothing to compare against, so the gate degrades to presence-checking exactly where the idea most needs teeth; default-REJECT can also breed decorative abstention [4].
- **Reconciliation:** The *evidence-typing + refuse-to-sum* half is strongly grounded and safe to adopt; the *citation-defeats-theatre* half is verified for mechanical claims but has a real, unresolved hole for perceptual ones. Not a clean pass, not a refutation.

## Verdict
- **Verdict:** INCONCLUSIVE
- **Confidence:** 0.62
- **Justification:** The non-summation / evidence-typing architecture is well-grounded ([1][2] + working repo precedent), and the fatalistic falsifier ("no check can catch non-support") is refuted for mechanical citations by both literature and the repo's own §6.4. But the riskiest assumption remains unverified precisely for PERCEPTUAL claims — there is no ground-truth artifact for a `file:line` quote to be checked against, so the gate risks degrading to citation theatre exactly where it matters, and default-REJECT may itself induce decorative abstention [4]. ADVANCE would overclaim; REFUTE ignores strong backing.

## Constraint for next cycle
- **Constraint text:** The next design MUST test whether a PERCEPTUAL verdict's citation can be automatically shown to *support* (not merely accompany) its claim — since source-line quotes cannot entail a feel/hierarchy judgement, either bind perceptual ADVANCE to a mechanical proxy that IS checkable or force explicit abstention, and measure the non-supporting-citation rate before trusting the gate.
