## Idea echoed
- **Title:** Golden-master fossil oracle — separation in time from a past human perception
- **Description:** Treat each committed root screenshot as a *frozen human verdict*. The loop never judges beauty; it re-derives a structural fingerprint (DOM shape, design-token usage, ARIA landmarks, hit-target map) from source at review time and judges *divergence from a state a human already blessed*. New screens inherit the nearest sibling's contract. Includes a baseline-provenance lock and a `HEAD~1`→`HEAD` "pentimento" delta review.
- **Riskiest assumption:** The 16 PNGs correspond to identifiable current routes and a structural fingerprint can be meaningfully compared against them — i.e. the fossils are a usable oracle, not stale debris.
- **Warrant:** Fossils supply perceptual ground truth the loop cannot generate; TRIZ separation-in-time borrows a human perception that already happened.

## Steelman (1 paragraph)
An eyeless loop cannot originate a beauty verdict, but it does not need to: a human already looked and shipped. The load-bearing move is that the loop compares *structure re-derived from source* (token usage, landmark inventory, hit-target counts) against a prior committed state — this is textbook **approval/golden-master testing**, whose entire premise is "does output still match the version a human approved?" ([1],[2]). Structure is deterministic from source, so a structural fingerprint sidesteps the pixel-flakiness that dooms naive screenshot diffs, and the pentimento `HEAD~1`→`HEAD` delta is exactly the "reviewer sees only the change" workflow that gives approval testing its power ([1]).

## Toulmin decomposition
- **Claim:** The 16 root PNGs are a usable golden-master oracle the loop can judge divergence against.
- **Grounds:** All 16 PNGs were committed in ONE commit `43e273b` ("checkpoint…autonomous UX loop") on 2026-06-20, with **zero prior `--follow` history** — never iterated in git [3]. Their names denote exercise-widget/component concepts (`arena`, `plot`, `ide`, `presets`, `calltree`), not routes: `src/app/` has NO `/arena`, `/plot`, `/ide`, `/calltree`, `/sales-nocode` route [4]; `arena`/`plot`/`ide` live inside `src/app/_components/exercises/` and `presets` is `src/app/playground/presets.ts` [5]. `calltree` and `sales-nocode` match **0 files** in `src/` [6].
- **Warrant:** A frozen human perception is a valid oracle *only if* it can be re-anchored to current source and is a version a reviewer actually inspected ([1],[2]).
- **Backing:** Approval testing = "compare produced content to a stored baseline; mismatch → reviewer diffs and promotes intended change" [1]; "the difference between approval testing and careless snapshotting is **review discipline**" [2].
- **Qualifier:** Holds only where a PNG maps to a stable route AND predates no source change. That set is ≈1 (`settings-page.png` → `src/app/settings/`, but `settings` was modified 2026-06-24, *after* the 06-20 fossil) [7].
- **Rebuttal (fires):** Fossils are 2026-06-20; every plausibly-mapped route was modified AFTER: `playground/generate` 07-17, `spaces` 07-18, `pricing` 07-17, `atlas` 06-22, `collection` 06-24 [7]. HEAD is 07-30. They are orphans — referenced only by *this cycle's own* brainstorm docs, nothing in `src/` [8].

## Falsification attempt
- **Falsifier proposed:** "If the PNGs cannot be mapped to current routes, or predate current source so badly no structural comparison is valid, there is no oracle — the fossils are debris."
- **Falsifier tested via:**
  - `git log --follow --format="%h %ad %s"` on all 16 → single commit `43e273b` 2026-06-20, no iteration history [3].
  - `find src/app -name page.tsx` + word-boundary grep → fossil names are exercise widgets/config, not routes; `calltree`,`sales-nocode` = 0 files [4][5][6].
  - `git log -1` per route dir vs fossil date → all mapped routes modified *after* 06-20 [7].
  - Python PNG-header read → small files (518×158/332/373) are inconsistent element crops, NOT blank; large ones are full-page (1200×690/734) — no uniform capture contract [9].
  - Orphan grep → zero references in `src/`/tests/CI [8].
- **Outcome:** **Confirmed falsifier.** Names don't map to routes, source post-dates every fossil, capture scope is inconsistent, and fossils are orphans.

## Position-swap reconciliation
- **Supporter reading:** Approval testing is legitimate and structural fingerprints beat pixels; `settings-page.png` shows *some* mapping exists, so the mechanism is sound even if the current corpus is thin.
- **Detractor reading:** The corpus IS the oracle, and it fails empirically: one undated batch, names ≠ routes, source drifted 27–40 days past capture, mixed crop scopes, orphaned. [2] warns "keeping every characterization file... preserve[s] behavior nobody wants" — baseline rot — and [2] requires determinism the stale PNGs can't satisfy.
- **Reconciliation:** Detractor wins on the fetched evidence. The *technique* is valid, but the idea's own riskiest assumption — these specific 16 PNGs as oracle — is falsified by git and the filesystem. A golden master nobody can re-anchor or prove was inspected is exactly the anti-pattern [2] names.
