## Decision Package — S11-B001

### Recommendation
- **Approach name:** A — Prefer `test.knowledgePieceId`, delete sessionStorage contract
- **Rationale:** The piece id is already persisted on the test document when the user generates a test. Re-reading a never-written `sessionStorage` key is a liar contract that silently disables high-score improvements (`if (score >= 0.8 && knowledgePieceId)`) and can let generation fall back to a random/first piece. Use the Convex field; pass it into the three client fetch bodies.
- **Why not alternatives:** Reinstating writers (B) re-introduces dual sources of truth and tab/refresh edge cases. Full rewrite of generation plumbing (C) is YAGNI for this bug.
