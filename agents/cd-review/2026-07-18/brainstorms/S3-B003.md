## Recommendation
- Approach name: **A — Single "use node" action modules; delete duplicate actions from non-node files; align on prompt registry + GEMINI_MODEL default**
- One-paragraph rationale: The comment in the Actions files already states the architectural rule: Node deps live only in `"use node"` action files. The non-node `generateImprovements` / `chat` actions are the legacy/wrong half of a split — they reintroduce `@google/genai` into the default Convex bundle path and drift from the live client entrypoints. Keep `knowledgeNodesActions.ts` / `testMessagesActions.ts` as the only public actions; port prompt-registry usage and model default from the non-node versions into Actions; strip Gemini imports/actions from `knowledgeNodes.ts` / `testMessages.ts` (leave queries/mutations/internal helpers).
- Why not B (keep both, document): doubles maintenance forever. Why not C (move all AI to Next API only): larger product boundary change; Actions path already used by chat route.
