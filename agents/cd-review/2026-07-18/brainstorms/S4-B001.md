## Decision Package — S4-B001

### Recommendation
- **Approach name:** B — Extract display/codeProbe validators; close reaction refs to open `event` root only
- **One-paragraph rationale:** The file is the authoring gate for the entire exercise pipeline. The high-leverage clarity wins are (1) peel `validateDisplayLayer` / `validateCodeProbe` / `shapeExprPairs` / `gatherObsSchema` into a sibling module so the top-level `validateSpec` reads as a pipeline, and (2) stop treating reaction RHS as ref-open: allow only known state/binding keys plus the root `event` (payload fields stay open via member access, which the ref walker already treats as root `event` only). That catches `ghost`/`counnt` typos while preserving `event.value` / free payload keys.
- **Why not the alternatives:** Full rewrite into a schema library (A) is taste + risk on a hot path; “only extract, leave refs open” (C) leaves the real authoring bug.
