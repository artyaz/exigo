## Decision Package — S4-B004

### Recommendation
- **Approach name:** B — Extract `sandboxShared.ts` (blocked globals + fmt + toValue + invokeInSandbox)
- **One-paragraph rationale:** The two harnesses are different *products* (trace/result vs observation probes) but share one *mechanism* (shadow dangerous globals, run strict source, coerce values). Extract the mechanism; keep two thin harness objects. That stops list drift and shortens both files without a premature “one harness to rule them all.”
- **Why not the alternatives:** Merge into single harness with modes (A) blurs API and edit-mode stories; leave duplicate (C) guarantees future drift (already visible).
