# Decision Package — S8-B001

**TRIGGER:** inconsistency + structure (hot-path SSE)  
**NORTH_STAR_HURT:** consistent, readable, clear  
**LOCATION:**  
- `src/app/api/learn/teach/route.ts` (SSE `data: {type:"delta"|"done"|"error"}`)  
- `src/app/api/learn/clarify/route.ts` (same; extra headers)  
- `src/app/api/tests/generate/route.ts` (same; raw error strings)  
- `src/app/api/learn/tutor/route.ts` (`event:` named lines + `data:`)  
- Clients: `src/app/spaces/.../page.tsx`, `CourseTutor.tsx`, `tests/[testId]/page.tsx`  

**SYMPTOM:** Four AI streaming routes claim “SSE” but use two wire protocols and three header sets. Engineers (and clients) cannot share one parser.

**EVIDENCE:**
- teach/clarify/generate: `` `data: ${JSON.stringify({ type: "delta", text })}\n\n` ``
- tutor: `` `event: ${event}\ndata: ${JSON.stringify(data)}\n\n` `` via `sseEvent()`
- Headers: teach/generate/tutor = `Cache-Control: no-cache`; clarify adds `no-transform` + `X-Accel-Buffering: no`
- Stream error: teach/clarify opaque (`"Teaching failed"`); generate leaks `err.message`

**QUESTION:** One wire format + helper, or tolerate dialects and only extract framing?

## Decision Package — S8-B001

### Recommendation
- **Approach name:** A — Shared SSE framing + document majority dialect; keep tutor named-events until client can migrate
- **One-paragraph rationale:** AGENTS.md specifies `delta`/`done`/`error` events. Three of four routes already use **type-in-JSON-payload** over a single `data:` line; only tutor uses standard named SSE events (needed today for `tool_call` / `tool_result` / `chat_created`). Extracting `encodeSseMessage` / `sseResponseHeaders` / stream error helper removes ~15 lines of copy-paste per route and freezes one header set. Forcing tutor onto type-in-payload in the same change requires `CourseTutor.tsx` (S7 ownership) — do that as a follow-up pack with both files, not as an API-only rewrite.
- **Why not the alternatives:** B is pure rename with zero shared helper — debt remains. C (full AI gateway) is YAGNI and out of north-star scope.

### Approaches considered

### Minimal implementation sketch
- Files to touch: new `src/lib/sse.ts`; migrate teach, clarify, generate, tutor to use it; optional tiny unit test for framing.
- Steps:
  1. Add `sseData(payload)`, `sseNamedEvent(event, data)`, `SSE_HEADERS` (include `no-transform` + `X-Accel-Buffering: no` like clarify).
  2. Replace inline `encoder.encode(\`data: ...\`)` with helpers.
  3. Stream errors: public message opaque; log real error with otlp (teach pattern).
  4. Do **not** change CourseTutor wire format in this pack unless S7 is co-owned.
- What NOT to do: rewrite Atlas NDJSON; invent a gateway; change product event payloads (`done` fields).
