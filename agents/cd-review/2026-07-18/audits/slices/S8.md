## Findings

### F-S8-001 — SSE wire protocol and response headers forked across AI streams
| Field | Value |
|-------|--------|
| **Severity** | **P1** |
| **Category** | inconsistency / structure (hot path) |
| **Location** | `learn/teach`, `learn/clarify`, `tests/generate`, `learn/tutor` |
| **Evidence** | teach/clarify/generate emit ``data: {"type":"delta",...}``; tutor emits ``event: delta\ndata: {...}``. Clients diverge: learn page parses `payload.type`; `CourseTutor.tsx` parses `event:` lines. Headers: clarify uses `no-cache, no-transform` + `X-Accel-Buffering: no`; siblings omit both. Stream error opacity differs (opaque vs raw `err.message` in generate). |
| **North-star harm** | **Consistent / readable** — one mental model broken; every new stream re-invents framing. |
| **Minimal fix** | Extract `src/lib/sse.ts` (`sseData`, `sseNamedEvent`, shared `SSE_HEADERS`); migrate four routes; keep tutor dialect until S7 client co-migrates. See brain package. |
| **Effort** | S–M |
| **Test plan** | Unit-test framing helpers; smoke each stream still yields deltas for existing clients. |
| **Brainstorm** | `audits/brainstorm/S8-B001.md` |

## Patterns

1. **Advanced convention exists but is unevenly applied** — Clerk → `createAuthedConvexClient` → prompts → Gemini → SSE/PostHog is the intended AI route shape; teach and generate are closest; clarify/tutor/feels-hard lag.
2. **Two intentional AI stacks** — product Gemini routes vs playground `resolveAiProvider`; undocumented at the API layer.
3. **SSE is the highest-churn inconsistency** — wire format, headers, error payloads, and client parsers all forked (loop worked example S8 matches reality).
4. **Copy-paste helpers** — `getAiClient`/`getModel`, stream encoder blocks, ConvexAuthError catch.
5. **God modules** — tutor >> generate > validate.
6. **Authz often delegated to Convex** — lesson/course getters check ownership; good. Space checks explicit on tests/* ; weaker explicitness on generate/* playground (user-scoped only).
7. **Observability split** — otlp + PostHog AI on mature routes; silence or `console.error` elsewhere.
