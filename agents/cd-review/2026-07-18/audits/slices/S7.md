### F-S7-001 — Course learn `page.tsx` is a multi-phase god page (~2080 lines)
- **Severity:** P1  
- **Category:** structure / clarity  
- **Location:** `src/app/spaces/[spaceId]/learn/[courseId]/page.tsx` (entire file; sections ~L171–450 shell, ~L452–868 Baseline, ~L870–899 Generating, ~L901–2002 Lesson, ~L2004–2080 Summary)  
- **Evidence:** Single client module owns route params/auth/queries, focus-mode keyboard, tab UI, baseline card arena + adaptive question gen, module advance spinner, full lesson teach/checkpoint/clarify runtime, and summary advance. Named phase components already exist *inline* but the file is still one scroll archaeology site.  
- **North-star harm:** Readability #1, Clarity #2 — competent engineer cannot hold the file in working memory; mixed UI+data+AI expected and confirmed.  
- **Minimal fix:** Split along existing phase boundaries into colocated modules; keep `page.tsx` as thin shell.  
- **Effort:** M  
- **Test plan:** Manual smoke: baseline → generate → lesson stream → checkpoint → summarize → summary continue; deep-link `?lessonId=`.  
- **Brainstorm:** `audits/brainstorm/S7-B001.md` (recommend **B**)

### F-S7-002 — Triplicated client SSE readers; inconsistent dialects; silent errors

- **Category:** inconsistency / AI streaming  
- **Location:**

## Patterns

1. **Incomplete extractions leave corpses** — Test UI was extracted to `TestGenerateButton`/`TestGrid`, but space page kept state/helpers; portal comment survived after clarify moved to block appendages.  
2. **SSE is copy-pasted at every AI surface** — tutor / teach / clarify each reimplement stream parsing; dialects already diverge.  
3. **Phase/state-machine UI lives in route files** — course orchestration phases mirror backend (`baseline` → … → `completed`) but frontend phases are monolith components, not modules.  
4. **Presentational islands are healthier** — `SelectionBubble`, `ClarificationThread`, `LessonPractice`, `spaces/page.tsx` list are closer to north-star size.  
5. **Error UX is uneven** — spaces list: inline error + PostHog; space detail knowledge: `alert()`; CourseTutor: silent; LessonPhase: red text.
