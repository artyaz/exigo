## Idea echoed
No script-eval tool exists, so the loop cannot compute contrast/hit-target and AC-02 forbids narrating unmeasured numbers. Fix: composite *known references* into the frame — (a) an acuity ladder of token-derived contrast swatches (3:1/4.5:1/7:1); verdict names lowest tier still legible. (b) a fixed 24px scale bar; hit-target read off the image against it. Riskiest assumption: a VLM reading against an in-frame reference produces *reliable* comparative measurement, not noise.

## Steelman
This is strictly comparative, not assertive: it never emits "4.5:1" — only "tier X still legible." That defuses the AC-02 fabrication that a bare screenshot invites (skeptic B-004-002:23). VLMs excel precisely at the ladder's shape: on well-separated, disjoint primitives BlindTest models score near-100%, and GPT-4o already "performs very well" on Snellen/tumbling-E/contrast-sensitivity charts — the authors excluded them as *too easy* [C1]. A 3-swatch ladder + one 24px block is a coarse, wide-spaced discrimination, not a fine one.

## Toulmin decomposition
- **Claim:** In-frame references let a VLM yield trustworthy comparative metrology where no script-eval exists.
- **Grounds:** AC-02 forbids un-sourced numbers, no `BrowserEvaluate`/`getComputedStyle`/`getBoundingClientRect` [loop-scope.md:81; recon/bench-results.md:33]. VLMs near-100% on spaced primitives & standard acuity charts [C1].
- **Warrant:** Naming a legible tier / "bigger than 24px" is a coarse discrimination VLMs do reliably.
- **Backing:** Optometry/forensic scale-bar precedent [B-004-004:48].
- **Qualifier:** Holds only for *coarse, well-separated* tiers; degrades to noise as tiers/targets crowd [C1,C2].
- **Rebuttal:** Visual comparison is a "systematic blind spot" — even GPT-5/Claude fail *trivial* geometric length/width/height comparisons and counting [C2]; and legibility ≠ WCAG's computed luminance ratio [AC-02 recon:12], so the ladder measures an *adjacent* construct.

## Falsification attempt
Prediction: if a VLM is shown the *same* capture N times, tier/size verdicts flip run-to-run, or it misranks a controlled A–D size set. CompareBench is exactly this test and reports models "often make mistakes in basic counting and geometric comparisons trivial for humans" [C2] — falsifier *fires* for fine/crowded cases. But BlindTest shows the crowding is the driver: add space → near-100% [C1]. So the falsifier is defeated only under a hard spacing/coarseness constraint, not in general.

## Position-swap reconciliation
- **Supporter (on C1):** coarse 3-tier ladder + single scale bar sits in the near-100% regime; comparative framing is safer than a fabricated ratio.
- **Detractor (on C2):** VLM geometric comparison is an actively-benchmarked failure; authoritative-looking tier/size numbers can be run-to-run noise — worse than abstaining, and it proxies WCAG rather than computes it.
- **Reconcile:** Both cite live evidence. The mechanism is *conditionally* sound: reliable only if tiers stay ≥1 step apart, references are disjoint from the component, and each read is repeated (self-consistency) with disagreement → abstain. Unqualified, it manufactures noise.

## Verdict
**INCONCLUSIVE**, confidence 0.66. Evidence supports the mechanism only under untested spacing/repeat-consistency guards; general VLM comparison unreliability (C2) blocks ADVANCE, coarse-case success (C1) blocks REFUTE.

## Constraint for next cycle
**MUST_TEST:** Before trusting any ladder/scale-bar read, prove run-to-run consistency on a fixed capture and correct ranking of a known coarse reference set; on disagreement the loop MUST abstain, and any tier claim MUST stay labelled a legibility proxy, never a WCAG ratio.
