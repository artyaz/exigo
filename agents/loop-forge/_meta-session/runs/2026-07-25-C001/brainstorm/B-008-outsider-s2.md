## Ideas

### I-001-MYC: Anastomosis registry
- Source domain: Mycology (fungal mycelia)
- Source-domain scale: hypha → mycelium → fruiting body (organism)
- Loop-forge scale applied: loop → loop-family → loop-ecosystem
- Analogous mechanism: Compatible mycelia fuse (anastomosis) and share cytoplasm; incompatible contact is walled off. A resource-rich patch triggers localized fruiting.
- Loop-forge protocol decision: Composition is an anastomosis test, not a merge — two loops compose only if their contracts (harness, archive schema, stop-grammar) pass a compatibility check. Mid-task extraction = fruiting: a rich sub-problem commits a frozen LOOP.md + reuse seed into the extracted-loops registry.
- Why the analogy holds at this scale: portfolios, like mycelia, gain capability by selective fusion, not universal merger.
- Riskiest assumption: compatibility is decidable from contracts without a dry-run.
- Warrant: selective fusion is what lets a portfolio grow without collapse.

### I-002-JUR: Stare decisis for composed loops
- Source domain: Common-law precedent (constitutional doctrine)
- Source-domain scale: case → doctrine → constitutional principle (one legal system)
- Loop-forge scale applied: loop-pair → composed-loop → composition-pattern
- Analogous mechanism: A ruling binds later structurally-similar cases; a novel case spawns a new doctrine rather than distorting an old one.
- Loop-forge protocol decision: Every composed loop (loop-forge ⊕ X) MUST cite one prior composed-loop run as precedent; if none fits, the agent MUST extract a new composition-pattern loop. Failed compositions are archived as dissents with reversal flags.
- Why the analogy holds at this scale: composition patterns accumulate authority only through reuse, exactly like doctrine.
- Riskiest assumption: "structurally similar" is computable from loop metadata.
- Warrant: forcing precedent-or-split prevents silent overload of existing loops.

### I-003-TRA: Autonomy transect zoning
- Source domain: Urban planning (New Urbanism transect T1–T6)
- Source-domain scale: parcel → neighborhood → city (spatial)
- Loop-forge scale applied: loop-rule → loop-family-zone → portfolio-region
- Analogous mechanism: A transect codes zones from wildland (T1) to urban core (T6); each zone calibrates the same rule categories to its intensity; cross-zone development is gated.
- Loop-forge protocol decision: The reconnaissance wave *zones* the target into one of six transects (T1 read-only-scout … T6 full-write-prod) and inherits that zone's calibrated rules. Composition is permitted only between adjacent transects; T1 ⊕ T6 is refused.
- Why the analogy holds at this scale: portfolio risk, like urban risk, is a function of intensity, not of domain.
- Riskiest assumption: six transects span every realistic domain.
- Warrant: zoning compresses the autonomy-design space into a tractable menu.

### I-004-SAUC: Mother-loop derivatives
- Source domain: Cuisine (Escoffier mother sauces)
- Source-domain scale: sauce → derivative → menu (kitchen)
- Loop-forge scale applied: base-loop → derivative-loop → loop-family
- Analogous mechanism: Five mother sauces; every derivative is a mother + one swap (Béchamel → Mornay = +cheese). Deglazing captures a by-product mid-cook and seeds a new sauce.
- Loop-forge protocol decision: Exigo's mother loops are cd-review (critical), brainstorm (divergent), loop-forge (meta). Every new loop MUST be declared as mother + single swap. Mid-task extraction = deglaze: sub-problem by-products become derivatives with an explicit swap-list.
- Why the analogy holds at this scale: derivability, not novelty, makes a family tractable.
- Riskiest assumption: the design space is reachable by single swaps.
- Warrant: the swap-list makes composition auditable.

### I-005-MORPH: Agglutinative loop grammar
- Source domain: Linguistics (agglutinative morphology, e.g. Turkish)
- Source-domain scale: morpheme → word → sentence (one language)
- Loop-forge scale applied: loop-morpheme → loop-word → composed-loop-statement
- Analogous mechanism: Each morpheme has a fixed meaning and slot; new words are coined by ordered concatenation with case markers — order is grammatical, not semantic.
- Loop-forge protocol decision: Treat each loop as a morpheme with a fixed IO contract (input-slot, output-slot, stop-condition). Composition = concatenation with case-markers (adaptation layers mediating slot mismatches). The authoring wave outputs a LOOP.md plus a *parse* of the loop as morphemes + markers.
- Why the analogy holds at this scale: combinability is exactly morphological well-formedness.
- Riskiest assumption: loops have stable IO slots analogous to morpheme slots.
- Warrant: a grammar makes composition decidable without semantic reasoning.
