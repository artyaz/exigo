## Ideas

### I-001-CONV: Self-amending convention charters
- Source domain: constitutional conventions.
- Analogous mechanism: A convention drafts a constitution embedding its own amendment procedure (Article V), then dissolves. Future revisions follow the rule the convention wrote; the document defines who changes it.
- Loop-forge protocol decision: loop-forge runs as a temporary convention emitting a loop spec plus that loop's modification procedure, then exits. Created-loop autonomy criteria live inside the spec, not in loop-forge.
- Why the analogy holds: a constitution is a law that makes laws; loop-forge is a loop that makes loops.
- Riskiest assumption: the self-declared amendment procedure is honored rather than bypassed.
- Warrant: autonomy is structurally a self-amendment clause.

### I-002-MORPH: Lineage commitment + reprogramming handle
- Source domain: stem-cell morphogenesis.
- Analogous mechanism: Transcription factors (e.g., MyoD) commit a cell to a lineage; the genome is preserved. Yamanaka factors erase epigenetic marks and reprogram a committed cell back to pluripotency — extraction to a universal state is biologically real.
- Loop-forge protocol decision: every created loop carries a lineage-commitment tag (active capability subset) plus a preserved reprogramming handle that re-derives loop-forge's core from any mid-task state. Mid-task extraction = invoke the handle, not snapshot state.
- Why the analogy holds: differentiation = specialization; Yamanaka reprogramming = mid-task extraction to a universal core.
- Riskiest assumption: reprogramming is cheap enough to be called "mid-task."
- Warrant: mid-task extraction is reprogramming, not checkpointing.

### I-003-ZONE: Overlay composition of use-districts
- Source domain: urban zoning.
- Analogous mechanism: Zoning ordinances define use-districts with permitted/conditional/prohibited uses. Overlay districts (historic, floodplain) stack on base zoning without rewriting it; conflicts route to a board of adjustment. Composition is spatial, not parametric.
- Loop-forge protocol decision: loop-forge emits loops as three-tier use-district specs; loops combine via overlays — a new loop stacks constraints on an existing one; overlay conflicts route to an appellate layer.
- Why the analogy holds: overlay zoning is the canonical combinable, mid-stack-revisable rule system.
- Riskiest assumption: overlay conflicts resolve without a human board of adjustment.
- Warrant: combinability is structurally an overlay mechanism, not parameter-passing.

### I-004-PREC: Interlocutory extraction via precedent log
- Source domain: common-law precedent (stare decisis).
- Analogous mechanism: Courts issue holdings followed until distinguished or overruled. Interlocutory appeals pause a case mid-trial, certify a question upward, get a ruling, then resume — precedent is consulted and created mid-case without aborting it.
- Loop-forge protocol decision: every created loop keeps an append-only precedent log; any running instance may issue an interlocutory extraction (pause, query/appeal upward, resume with ruling). Extraction is a procedural pause, not a state dump.
- Why the analogy holds: interlocutory appeal is the legal analog of pause-and-resume mid-task.
- Riskiest assumption: a higher-order loop exists to which appeal is meaningful.
- Warrant: mid-task extraction is structurally an interlocutory procedure.
