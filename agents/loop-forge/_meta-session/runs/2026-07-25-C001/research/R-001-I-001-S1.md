## Idea echoed
- Title: Wave Ω — Domain reconnaissance with adversarial autonomy-criteria slots.
- Description: Mandatory Wave Ω before protocol authoring; agent dispatches N cheap probes, derives autonomy criteria, admits each only if an Autonomy-Adversary slot fails to find a hidden HITL after N rounds against an Autonomy-Realist slot.
- Riskiest assumption: (1) autonomy criteria reliably inferrable from probe responses vs. expert-declared; (2) the Adversary slot genuinely catches hidden HITL rather than rubber-stamping the Realist.
- Warrant: cd-review §4 slice map + brainstorm §6.3 capped DA re-dispatch — same primitives generalized.

## Steelman (1 paragraph)

Wave Ω fixes the brittleness every domain-specific protocol inherits: a hard-coded autonomy table is wrong the moment the deployment environment changes. Rather than guess at author time, the loop dispatches cheap no-op probes and reads back the actual signal surface. The structural innovation is the mandatory two-slot adjudication — Realist proposes from failure modes, Adversary hunts for hidden HITL — the dual mechanism brainstorm §6.3 already uses and cd-review enforces (§0.5.3, §8.6.1), applied one wave earlier.

## Toulmin decomposition
- Claim: Autonomy criteria for a loop-forge-emitted loop can be reliably inferred at runtime from probe responses and certified by an adversarial slot, removing the need for a domain expert.
- Grounds:
  - Knight Columbia (Feng et al., Jul 2025): autonomy is a "design decision" separate from capability; flags L4 "rubber stamping" [1].
  - cd-review §0.5.3 (lines 84-99) hard-bans HITL primitives — the invariant the Adversary detects [2].
  - cd-review §4 (lines 226-242): runtime discovery of audit scope — same primitive generalized [3].
  - brainstorm §6.3 (lines 611-627): all-advance DA re-dispatch — Adversary slot lifted one wave earlier [4].
  - brainstorm §8.6 line 1060 invariant rule 1 gives the Adversary a pass/fail target [5].
  - arXiv 2604.00478 validates "dynamic behavioral gating for anti-sycophancy" [6].
- Warrant: If a black-box system's I/O surface is causally correlated with its internal state, and an adversarial reviewer reduces sycophantic echo, then probe-derived criteria + adversary certification should yield a more accurate autonomy surface than author-time declaration.
- Backing: Active probing is established for black-box inference (Oh et al.; IREEN). Feng et al. (2025): autonomy is orthogonal to capability.
- Qualifier: Holds only if (i) autonomy surface observable externally (no silent HITL), (ii) Adversary sees Realist's traces, (iii) N rounds covers failure-mode space.
- Rebuttal: If LLMs underperform at black-box inference (2505.17968), or the Adversary collapses into theater (TechTarget 2026), Wave Ω produces criteria both wrong and self-certified — worse than no certification.

## Falsification attempt
- Falsifier proposed: If LLMs cannot reliably reverse-engineer black-box structure from active probing, autonomy-criteria inference is unreliable, and Wave Ω's first half collapses.
- Falsifier tested via: web_search → arXiv 2505.17968 (Geng et al., May 2025) — fetched live (HTTP 200); "4.1 LLM Struggles to Identify Black-Box Functions"; "Bayesian inference algorithms increasingly outperformed LLMs" (p=0.002). Secondary: arXiv 2604.17609 — fetched live (HTTP 200); discover 79-81% / exploit 37-50%; AppWorld >90% discovery / <7% exploit.
- Outcome: confirmed falsifier (partial). Inference half contested; Adversary-slot half structurally supported but inherits the rubber-stamping risk TechTarget documents.

## Position-swap reconciliation
- Supporter reading: Two-slot primitive is what brainstorm §6.3 uses and 2604.00478 validates. Knight Columbia confirms autonomy is a design decision separate from capability. Adversary is the protection against inference being wrong.
- Detractor reading: Halves not separable. If Realist input unreliable (2505.17968), Adversary certifies a noisy set; if Adversary rubber-stamps (TechTarget), no protection. 2604.17609 decisive: agents discover but don't exploit. No published evidence Adversary catches structurally-hidden HITL.
- Reconciliation: Detractor wins. 2505.17968 tests inference and finds LLMs underperform; 2604.17609 tests probe-to-action and finds a 30-80pp gap. Adversary half has precedent but no evidence it catches its mandated failure mode.

## Verdict
- Verdict: INCONCLUSIVE
- Confidence: 0.62
- Justification: First half (probe → criteria) empirically contested by direct measurement (2505.17968; 2604.17609). Second half (Adversary catches hidden HITL) structurally supported but lacks published evidence an LLM adversary reliably catches structurally-hidden HITL — may itself be a rubber stamp (TechTarget 2026).
