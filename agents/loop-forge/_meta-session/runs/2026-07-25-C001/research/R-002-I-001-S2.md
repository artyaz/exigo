## idea echoed
Three structural mechanisms: (a) any subagent may file `loop-itch.md` when its sub-problem exhibits autonomy-envelope properties; orchestrator promotes top-itched sub-problems to mid-cycle extraction. (b) Every LOOP.md header carries `remaining_extraction_depth` (default 3); mid-task extraction MUST decrement child's header; depth=0 forbids extraction and forces inline; orchestrator refuses to dispatch a child whose depth ≥ parent's depth (hard invariant). (c) Loop-scope agent writes `extract/{name}.md` (partial LOOP.md slice, trigger, residual scope); launcher spawns parallel child loop-scope agent; parent LOOP.md gains `composes-with:` ref on child ship.

## steelman
I-001-S2 generalizes three exigo primitives to a new scale: itch-filing generalizes brainstorm's persona×seed diversification-as-detection (`B-001-dreamer-s1.md:44`); the depth-budget header field mirrors cd-review §0.5.3's hard no-HITL rule (`cd-review/LOOP.md:84-99`); checkpointable extraction generalizes brainstorm §8.2.2's mid-wave re-entrancy (`brainstorm/LOOP.md:937-970`) from "mid-wave" to "mid-loop." The riskiest assumption is bounded by (b): a false-positive itch at depth=0 inlines harmlessly; a false-negative just delays. Asymmetry is favorable.

## Toulmin decomposition
- **Claim:** Mid-task extraction is safe iff bounded by a hard, header-carried depth budget.
- **Grounds:** (1) arXiv:2607.01641 — IAL-Scan on 6,549 LLM agent repos, 68 IAL failures across 47 projects at 91.9% precision; root cause uniformly "feedback path not effectively bounded" (https://arxiv.org/abs/2607.01641). (2) kilocode #8637 — production unbounded subagent recursion; recommended fix #1 verbatim: "Maximum nesting depth — Track depth on sessions via the parentID chain and refuse to create sessions beyond a threshold (e.g. 3). This is the most robust guard and is independent of permission configuration" (https://github.com/Kilo-Org/kilocode/issues/8637). (3) cd-review forbids child spawning at six points (`cd-review/LOOP.md:183,252,271,323,339,466`) — primitive absent from existing loops, IAL risk is the stated reason. (4) brainstorm §8.5 (`brainstorm/LOOP.md:1025-1054`) uses layered stop conditions; depth-budget is the same pattern on the recursion axis.
- **Warrant:** A bound is effective only if it sits ON the path being bounded — agentpatterns.ai: "a visible exit condition can sit outside the actual feedback path and never gate it" (https://agentpatterns.ai/patterns/anti-patterns/unbounded-agent-feedback-paths). A header field checked at dispatch time IS on the path.
- **Backing:** Bounded recursion is textbook CS; kilocode independently converged on threshold=3 and "independent of permission configuration" (hard, not advisory) — matching I-001-S2 verbatim (`B-003-skeptic-s1.md:21`).
- **Qualifier:** Holds for default depth=3 in domains where autonomy-envelopes nest ≤ 3 deep.
- **Rebuttal:** If itch-detection has > 50% false-positive rate at depth=0, the inline-fallback produces strictly worse loops than no-extraction baseline (see falsification).

## falsification attempt
**Plan:** Implement I-001-S2 sandboxed. Construct 20 seeded sub-problems: 10 with genuine autonomy-envelope properties (independent decision points, own stop conditions) and 10 "merely hard." Measure: (i) itch-filing precision/recall vs. ground-truth labels; (ii) end-to-end LOOP.md quality delta for extracted-vs-inlined at depth=0. **Kill condition:** if precision < 0.6 OR quality-delta(extracted) − quality-delta(inlined) < 0 at depth=0 across ≥ 15 of 20 cases, the primitive's discrimination is below the threshold where (b)'s bound makes the system safe-but-useless. **Not yet run** — routed to next-cycle constraint.

## position-swap reconciliation
Skeptic stance: the depth budget backstops a primitive that may not deserve to exist; cd-review forbids children for a reason. But kilocode cuts both ways: production systems ALREADY recursively spawn subagents; forbidding the primitive doesn't prevent the failure, it makes it uncontrolled. A header-carried hard depth budget is strictly safer — it converts uncontrolled recursion into controlled. Strongest counter (depth=3 is arbitrary) is partially answered by kilocode's independent convergence on 3, but the depth choice is empirically open. Reconciled: ADVANCE; gate the depth default behind the falsification result.

## verdict
**ADVANCE.** Grounds confirm: (i) failure mode is real and measured (arXiv:2607.01641); (ii) the proposed fix matches an independent production system's recommended fix, including threshold value (kilocode #8637); (iii) the structural mechanism ("hard, on-path, header-carried") matches the literature's prescription (agentpatterns.ai). Riskiest assumption (discrimination reliability) is bounded by the depth=0 inline-fallback; second risk (depth=3 sufficiency) is empirically open and routed to next cycle.

## constraint for next cycle
**C-001-R002:** loop-forge's first self-simulation (Wave γ) MUST include a discrimination test bench: ≥ 20 seeded sub-problems labeled {deserves-extraction / merely-hard} with ground-truth labels; report itch-filing precision/recall AND quality-delta(extracted) − quality-delta(inlined) at depth=0. If precision < 0.6 OR delta < 0 across ≥ 15 cases, the depth default MUST be revised (down to 2 with stricter itch criteria, or up to 4). Blocks ship of any LOOP.md omitting the test bench.
