## Decision Package — S4-B007

### Recommendation
- **Approach name:** B — Incremental VM clone-or-fork per edge; keep JSON key for now with a short comment; optional structural clone helper
- **One-paragraph rationale:** Correctness of the search is fine for current tests. The clarity win is making the algorithm match the mental model “from state S, try action A → state S'” instead of “re-run the entire history twice per edge.” Implement by cloning state/bindings (or `new ReactiveVM` + restore snapshot if API allows) and `dispatch` once. If VM lacks a cheap clone, add a package-private `fork()` that deep-clones state and copies compiled ASTs by reference. That shortens the mental model and cuts O(depth) factor. Fingerprint can stay JSON until a real collision shows up — don’t invent a perfect hash.
- **Why not the alternatives:** Full rewrite to SAT (A) absurd. Micro-opt only (C) without structural clarity miss the point of the audit.
