## Recommendation
- Approach name: **Shared ownership helpers + gate public writes**
- One-paragraph rationale: Course domain already mixes three auth styles (`getAuthedContext`+`requireEducatorAccess`, bare `getAuthenticatedUserId`, and “trust the client”). The dangerous holes are not plan-tier cosmetics — they are missing resource ownership on AI entrypoints and a free-form public phase write. Fix by (1) one internal helper “load course for user or throw”, (2) space ownership before `createInternal`, (3) educator gate on all course writes, (4) delete or internalize dead `updatePhase` public mutation. Do not invent a full CASL layer.
- Why not the alternatives: Full policy framework is YAGNI; “only fix normalizeTopic” leaves baseline/phase holes that share the same root smell.

### Minimal implementation sketch
- Files to touch: `convex/courseAi.ts`, `convex/courses.ts`, `convex/courseLessons.ts`, `convex/courseTutor.ts`, optionally tiny helper in `convex/authDecorators.ts` or new `convex/courseAuth.ts`
- Steps:
  1. Add `assertOwnedCourse(ctx, courseId, userId)` / `assertOwnedSpace(...)` that throw ConvexError UNAUTHORIZED.
  2. `normalizeTopic`: after auth, `ctx.runQuery` space (or mutation path) and require `space.userId === auth.userId` before `createInternal`.
  3. `generateBaselineQuestion` / `evaluateBaselineAnswer`: load course via `getInternal`, require owner (+ educator already present). Prefer server `course.refinedTitle` over client `courseTopic` when available (or still accept topic but never skip ownership).
  4. Public `updatePhase`: delete if unused (grep shows no callers) or convert to internal-only; clients must use orchestrator.
  5. `updateBaseline`, checkpoint, feels-hard, tutor chat create/send: `requireEducatorAccess` for parity with course creation, **or** document FREE allowance intentionally — default recommend educator for all adaptive-course surfaces.
- What NOT to do: Don't rewrite to CASL; don't change Clerk middleware.
