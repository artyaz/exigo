## Recommendation
- Approach name: **Authenticate getPrompt; keep internal for trusted backends**
- One-paragraph rationale: Prompt text is product IP and an injection cookbook. `getPrompt` is a public Convex query with **zero** auth — any client that can hit the deployment URL can enumerate prompt names and exfiltrate system prompts. Next routes use it via user-authed ConvexHttpClient today, so requiring `getAuthenticatedUserId` is a one-line fix that preserves routes. Prefer not exposing prompts to pure anonymous clients. Optional later: restrict by name allowlist.
- Why not: Making prompts fully internal breaks ConvexHttpClient from Next unless routes use admin key (they shouldn't).

### Minimal implementation sketch

- Optionally return only `{ name, content }` without leaking description if needed — skip.
- What NOT to do: Don't put prompts back into source code.
