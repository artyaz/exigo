## Decision Package — S1-B002

### Recommendation
- Approach name: **Single auth surface in `authDecorators.ts`; delete dead `auth.ts` and unused wrappers**
- One-paragraph rationale: AGENTS.md advertises `getAuthedContext` / `withAuth` as the Convex auth convention, but production almost exclusively calls `getAuthedContext` / `getAuthenticatedUserId` / `getAuthedContextForAction` from `authDecorators.ts`. `convex/auth.ts` exports soft-null helpers with the same names and has zero importers. `withAuth` / `withAuthAction` are defined, documented, and never used — dead ceremony. Collapsing to one module with throw-on-missing-auth helpers (plus optional soft-identity helpers only if needed) restores the documented boundary.
- Why not the alternatives: Keeping both files "for actions vs queries" is a lie — both already live in decorators. Wrapping every handler in `withAuth` is a large cross-slice churn with little clarity gain.

### Minimal implementation sketch
- Files: `convex/auth.ts` (delete), `convex/authDecorators.ts` (trim), AGENTS.md is orchestrator-owned note for Phase C.
