## Decision Package — S9-B004

### Recommendation
- Approach name: **Keep 5s default (Paddle-aligned); document env override; shrink provider surface comments**
- One-paragraph rationale: Research and common Paddle examples use a **~5 second** signature timestamp window; the code already allows `PADDLE_WEBHOOK_TOLERANCE_SECONDS`. This is not a bug if clock sync is fine. The clarity/money issue is elsewhere: `IPaymentProvider` only exposes verify + CRUD, while the webhook **route** owns event typing, Convex admin calls, and Clerk metadata — so “payments boundary” is half-drawn. Do **not** move S8 route logic into S9 in this pack; instead document the split in `payments/types.ts` / `index.ts` and optionally raise default to **30s** only if ops evidence shows false rejects (env already supports it).
- Why not the alternatives: Parsing all Paddle events inside the provider couples domain billing state to a vendor SDK shape and expands ownership into S8.
